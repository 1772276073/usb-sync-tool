# USB 同步工具（便携版）

基于 rclone 的 U盘同步工具，**绿色免安装**：自带 rclone、无需配置，解压即用，换电脑拷贝整个文件夹即可。

---

## 🚀 快速开始

1. 解压 `USB-Sync-Tool-Portable.zip`
2. 双击 **`USB-Sync.exe`**
3. 填写本地路径和 U盘路径，选择同步模式
4. 点击 **开始同步**

> 无需安装 rclone、无需配置 PATH、无需管理员权限。整个文件夹拷到任何 Windows 10/11 电脑即可运行。

## 📌 方案预设

保存常用路径和同步模式，避免每次手输：

1. 填好路径、选好模式 → 点 **保存方案** → 输入方案名
2. 之后从方案下拉框选择，路径和模式自动填入
3. "删除"按钮移除不再需要的方案

方案保存在 `%APPDATA%\USB-Sync-Tool\profiles.json`，重启软件仍然存在。

**示例**：
- "工作文件"：`D:\Work\ProjectFiles` ↔ `G:\Work` + 推送到U盘
- "文档备份"：`D:\Documents` ↔ `G:\Docs` + 双向同步

## 🔄 同步模式

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| **双向同步** | 两端保持一致，任一端的更改同步到另一端 | 日常使用 |
| **推送到U盘** | 本地 → U盘，U盘额外文件保留 | 备份本地文件 |
| **从U盘拉取** | U盘 → 本地，本地额外文件保留 | 恢复文件 |
| **预览变更** | 显示将要执行的操作，不实际执行 | 同步前检查 |

> 双向同步首次运行时，工具会自动带 `--resync` 建立基准（正常现象，只需几秒）。

## 🗄 版本管理

被覆盖或删除的文件自动备份到备份目录（默认 `G:\.sync-backup`），带时间戳：

```
G:\.sync-backup\
├── document.txt.2026-08-25_143022
└── image.png.2026-08-25_143510
```

需要恢复时，从备份目录复制回原位置即可。备份文件会越积越多，建议定期清理旧备份。

## 🚫 排除规则

编辑 `sync-filters.txt` 自定义不同步的文件：

```
# 默认排除
- .DS_Store        # macOS 元数据
- Thumbs.db        # Windows 缩略图缓存
- desktop.ini      # 文件夹配置
- *.tmp            # 临时文件
- *.temp
- ~$*              # Office 打开时的锁文件

# 自定义示例
- *.log
- node_modules/**
- $RECYCLE.BIN/    # U盘回收站
```

| 符号 | 说明 | 示例 |
|------|------|------|
| `-` | 排除 | `- *.tmp` |
| `+` | 包含（优先级更高） | `+ important.log` |
| `**` | 匹配任意目录 | `- node_modules/**` |

## 💻 命令行版（可选）

不打开界面也能同步，适合定时任务：

```powershell
# 双向同步
.\sync-usb.ps1

# 推送到U盘
.\sync-usb.ps1 -Action push

# 从U盘拉取
.\sync-usb.ps1 -Action pull

# 预览变更
.\sync-usb.ps1 -Action status

# 自定义路径
.\sync-usb.ps1 -LocalPath "D:\MyFiles" -UsbPath "G:\MyBackup"
```

## ❓ 常见问题

### 同步中进度条不动 / 不知道是否卡死？
状态栏显示 **"同步中 mm:ss"** 实时计时——时间在走说明正常，同一时间点停留不动才是卡住。进度条为蓝色动画滚动。

### 双向同步提示"需要 resync"？
首次双向同步没有基准记录，工具已**自动**带 `--resync` 重试，无需手动操作。之后正常增量同步。

### 同步失败提示路径不存在？
1. U盘是否已插入
2. 路径是否正确（U盘盘符可能变化）
3. 是否有读写权限

### 备份文件太多？
备份目录会持续累积，定期手动清理 `G:\.sync-backup`（或你配置的备份目录）中的旧文件。

### 换电脑怎么用？
把整个 `USB-Sync-Tool-Portable` 文件夹拷到新电脑，双击 `USB-Sync.exe` 即可——不需要在新电脑安装任何东西。

### 想用另一个版本的 rclone？
把新的 `rclone.exe` 直接替换文件夹里的同名文件即可（自动优先使用同目录版本）。
