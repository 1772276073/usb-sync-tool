## 安装

### 1. 安装 rclone

打开 PowerShell（管理员模式），运行：

```powershell
winget install Rclone.Rclone
```

安装完成后重启 PowerShell。

### 2. 验证安装

```powershell
rclone version
```

应该显示 rclone 版本号（如 v1.75.0）。

### 3. 准备同步文件夹

```powershell
# 创建本地同步文件夹
mkdir synced

# 创建 U盘同步文件夹（插入 U盘后）
mkdir G:\synced

# 创建备份文件夹
mkdir G:\.sync-backup
```

## 启动

### 方法 1: 双击批处理文件

## 同步模式

### 双向同步

本地和 U盘保持一致。任何一端的更改都会同步到另一端。

**适用场景**：日常使用，保持两端文件一致。

**注意**：如果同一文件在两端都被修改，会产生冲突文件。

### 推送到U盘

将本地文件复制到 U盘，U盘上额外的文件不会被删除。

**适用场景**：备份本地文件到 U盘。

### 从U盘拉取

将 U盘文件复制到本地，本地额外的文件不会被删除。

**适用场景**：从 U盘恢复文件到本地。

### 预览变更

显示将要执行的操作，但不实际执行任何更改。

**适用场景**：在同步前查看会有什么变化。

## 版本管理

### 自动备份

当文件被覆盖或删除时，原文件会自动备份到 `G:\.sync-backup\` 目录。

### 备份文件命名

备份文件保留原始目录结构，文件名带时间戳后缀：

```
G:\.sync-backup\
├── 20260825_143022\
│   ├── document.txt.2026-08-25_143022
│   └── image.png.2026-08-25_143022
── 20260825_150000\
    ── old-file.txt.2026-08-25_150000
```

### 恢复备份

1. 打开 `G:\.sync-backup\` 目录
2. 找到需要的备份文件
3. 复制回原位置

## 排除规则

### 默认排除

`sync-filters.txt` 文件定义了默认排除的文件：

```
- .DS_Store
- Thumbs.db
- desktop.ini
- *.tmp
- *.temp
- ~$*
- .sync-backup/**
- rclone/**
```

### 自定义排除

编辑 `sync-filters.txt` 添加自定义规则：

```
# 排除所有 .log 文件
- *.log

# 排除特定目录
- node_modules/**
- .git/**

# 排除大文件
- *.iso
- *.zip

# 包含特定文件（覆盖上面的排除）
+ important.log
```

### 规则语法

| 符号 | 说明 | 示例 |
|------|------|------|
| `-` | 排除 | `- *.tmp` |
| `+` | 包含（优先级更高） | `+ important.tmp` |
| `**` | 匹配任意目录 | `- node_modules/**` |

## 常见问题

### Q: 首次同步提示需要 resync

**A**: 这是正常现象。rclone 的双向同步首次运行时需要建立基准。再次点击"开始同步"即可。

### Q: 同步失败，提示路径不存在

**A**: 检查：
1. U盘是否已插入
2. 路径是否正确
3. 是否有读写权限

### Q: 如何查看同步了哪些文件

**A**: 使用"预览变更"模式，或查看日志区域的输出。

### Q: 同步速度很慢

**A**: 可能原因：
1. USB 2.0 接口（约 30 MB/s）
2. 大量小文件
3. 首次同步需要建立基准

### Q: 如何取消同步

**A**: 点击"取消"按钮。注意：已传输的文件不会回滚。

### Q: 备份文件太多，如何清理

**A**: 定期手动清理 `G:\.sync-backup\` 目录，删除旧的备份。

### Q: 可以在没有 rclone 的电脑上使用吗

**A**: 不可以。rclone 是核心依赖，必须先安装。

## 技术细节

### 底层工具

- **rclone v1.75.0**：开源同步工具
- **PowerShell 5.1+**：Windows 内置脚本环境
- **.NET WinForms**：图形界面框架

### 同步原理

1. **文件比较**：rclone 比较文件大小和修改时间
2. **增量传输**：只传输变化的部分
3. **版本备份**：使用 `--backup-dir` 参数保留旧版本
4. **冲突处理**：双向同步时，冲突文件会重命名保留

### 性能参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 线程数 | 8 | 并行传输线程 |
| 重试次数 | 3 | 失败后重试次数 |
| 重试间隔 | 5秒 | 重试等待时间 |
| 传输模式 | 断点续传 | 中断后可继续 |

### 退出码

| 退出码 | 含义 |
|--------|------|
| 0 | 同步成功 |
| 1 | 需要重新同步（首次运行） |
| 2+ | 同步失败 |

### 日志级别

日志区域显示的信息包括：

- **时间戳**：`[HH:MM:SS]`
- **操作类型**：开始同步、同步完成、错误等
- **详细信息**：传输的文件数、速度、时间等

## 高级用法

### 命令行版本

如果不喜欢 GUI，可以使用命令行版本：

```powershell
# 双向同步
.\sync-usb.ps1

# 推送到U盘
.\sync-usb.ps1 -Action push

# 从U盘拉取
.\sync-usb.ps1 -Action pull

# 预览变更
.\sync-usb.ps1 -Action status
```

### 自定义路径

```powershell
.\sync-usb.ps1 -LocalPath "D:\MyFiles" -UsbPath "G:\MyBackup"
```

### 自动同步（可选）

创建 Windows 定时任务，每 30 分钟自动同步：

```powershell
# 以管理员身份运行（将下面的路径替换为你的 sync-usb.ps1 实际位置）
$action = New-ScheduledTaskAction -Execute "PowerShell.exe" -Argument "-NoProfile -WindowStyle Hidden -File `"C:\path\to\USB-Sync-Tool\src\sync-usb.ps1`""
$trigger = New-ScheduledTaskTrigger -Once -At (Get-Date) -RepetitionInterval (New-TimeSpan -Minutes 30)
Register-ScheduledTask -TaskName "USB Sync" -Action $action -Trigger $trigger
```
