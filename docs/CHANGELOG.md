## v2.1.0 (2026-11-18)

- 配色整体替换：深海军蓝底 `#101522` / 卡片 `#19202f` / 内层 `#222a3b` / 紫罗兰强调 `#9184ff`（上压墨字 `#111522`） / 青绿副色 `#57d2c8` / 危险 `#ff5c5c` / 文字 `#f2f4f8`
- 圆角体系：卡片 12px、控件 8px、分段容器药丸 10px
- 修复窗口半透明（透出桌面内容）与左上角标题重复（窗口标题栏已有全名）
- 路径输入收入卡片，连接状态提示内嵌到各输入框下方（青绿 ✓ / 红 ✗ / 黄 ⚠）
- 模式选择器：药丸容器 + 滑动指示块，选中项为紫罗兰底墨字
- 主按钮"开始同步"通栏大按钮（紫罗兰底墨字，预览模式自动变文案）；进度条填充与速度显示用青绿副色
- 修复日志区占满窗口导致底部按钮被挤出的问题；日志改用更深的内层底色
- 顶栏改为极简角标（USB SYNC · v2.1）+ 右侧状态脉动点

### 界面动效（依 modern-web-guidance 指南）
- 新增 `anim.rs` 动效助手模块：统一时长、缓动与降级开关
- 模式选择器：选中指示块在选项间平滑滑动（0.15s）
- 进度条：传输阶段填充平滑过渡（0.3s，不再跳变）；扫描/比对阶段显示不定态滑动块
- 扫描/比对阶段：阶段名前显示旋转弧线指示器（减弱动效时放慢 4 倍而非停止）
- 状态点：运行中柔和脉动光晕（≈0.9 次/秒，远低于 3 次/秒闪烁阈值）
- 按钮 hover：颜色平滑过渡（0.15s）
- 窗口入场：0.45s 淡入幕布
- 高级设置：改用自带展开/收起动画的折叠面板，新增"启用界面动画"开关

### 图标与安全
- 新增应用图标：eframe 默认图标（黑底白六边形风车）保留设计，背景重映射为 UI 海军蓝 `#101522`，多尺寸 .ico 嵌入 exe
- 目标文件为只读时拒绝覆盖（与 rclone 语义一致，按文件报错、不影响其他文件）
- 文件复制改为**原子写入**：先写 `.usb-partial` 临时文件再改名落盘——中断/崩溃不会在目标位置留下残缺文件；临时文件自动纳入默认排除规则
- **备份保留策略**：备份总量超过上限（默认 3GB，高级设置/CLI 可调，0=不限）时自动从最旧的运行目录开始清理；本次运行目录与最近一次备份永不删除；非时间戳命名的自放文件不触碰

### 工程
- 移除 filetime 依赖（改用 std::fs::set_times）
- 适配 egui 0.37 API（Id::unique、CornerRadius、on_exit 签名）；clippy 清零
- 日志绘制 O(n²)→O(n)

## v2.0.0 (2026-11-17)

### 重大变更
- **纯 Rust 重写**：原生同步引擎（并行扫描/快照比对/多线程复制），不再依赖 rclone 与 PowerShell
- 全新 egui 图形界面（Ant Design 深色主题、字节级实时进度、速度显示、优雅取消）
- 新增命令行 usb-sync-cli.exe（定时任务/脚本化）
- 单文件便携 exe，启动 < 1 秒

### 同步引擎
- 双向同步改为快照式（`<U盘>\.usb-sync\state.json`）：增删改双向传播、冲突新者胜+败者备份、首次自动合并（无需 rclone 式 resync）
- 推送/拉取：单向增量，对端多余文件保留
- 预览变更：纯 dry-run，不落盘
- mtime 2 秒容差（FAT32/exFAT 粒度）；复制后恢复源文件修改时间
- 备份目录改为 `<备份根>\<运行时间戳>\<相对路径>`（保留结构，可整体还原）
- 修复 v1 GUI 未应用排除规则的 bug；排除规则支持自定义并随方案保存
- 取消为协作式优雅停止；取消/出错不写快照，下次自动按首次合并处理
- profiles.json 兼容 v1（中文模式文案自动映射）

### 工程
- 构建：`usb-sync\build.cmd`（rustup stable-gnu + MSYS2 binutils）
- 测试：`cargo test` 单元测试 + `test-scenario.ps1` 八场景验证
- 构建产物 target-dir 移出 Obsidian 库（`E:\rust-target\usb-sync\`）
