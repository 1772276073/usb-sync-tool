# 更新日志

## v1.0.1 (2026-08-25)

### 修复
- 取消按钮现在会真正终止正在运行的 rclone 进程（之前只改状态文字）
- 修复退出码处理不一致：rclone 退出码 1（需要 resync）现在会正确传递，脚本不再静默返回 0
- 移除硬编码的 rclone 路径，改为自动查找（PATH → WinGet 目录）
- 修复同步进程输出较大时可能发生的管道阻塞死锁（改为异步读取）
- 修复路径含空格时 rclone 参数被错误拆分的问题（自动加引号）
- 修复同步脚本抛异常时 GUI 错误信息不明确的问题
- 更新文档中过时的定时任务路径示例

### 文件
- `rclone-locate.ps1` - 新增：rclone 自动查找函数
